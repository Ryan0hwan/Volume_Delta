# 거래량 델타 스캐너 (하루 · 5일 · 10일 매수 우위)

S&P 500 + 관심종목(`watchlist.txt`) + ETF(`etfs.txt`) 약 795개에서, **거래량 델타가 크게 플러스(매수 쏠림)** 인 종목을 **마지막 하루 · 5일 누적 · 10일 누적** 세 기간으로 찾아 디스코드로 보냅니다. **한국 시각 평일(화~토) 아침 07:30쯤** 도착합니다 (GitHub 사정으로 5~30분 늦을 수 있음, 실행에 15~20분 걸림).

## 델타 계산 방법

TradingView의 Volume Delta와 같은 방식(하위 시간봉 근사)입니다.

| 단계 | 계산 |
|---|---|
| 1 | 정규장(09:30~16:00)을 5분봉 78개로 나눔 |
| 2 | 종가 > 시가인 5분봉 거래량 = 매수, 종가 < 시가 = 매도 (같으면 직전 5분봉 종가와 비교) |
| 3 | **델타 = 매수 거래량 − 매도 거래량** |

실제 호가 체결(누가 매수 호가를 쳤는지) 데이터가 아니라 근사치라서 TradingView 값과 정확히 같지는 않지만, 방향과 크기는 대체로 비슷합니다.

## 알림 조건

### ① 하루 큰 양봉 (마지막 거래일 막대 하나)

| 조건 | 기준 | 뜻 |
|---|---|---|
| 매수 쏠림 | 델타 ÷ 그날 거래량 **+30% 이상** | 하루 거래 중 매수 쪽이 확실히 우세 |
| 이례적 크기 | 델타 ≥ 최근 20일 평균 델타 크기의 **2배** | 평소보다 훨씬 큰 양봉 막대 |

### ② 5일 · 10일 누적 매수 우위 (LEN처럼 큰 양봉이 여러 번 나온 모양)

| 기간 | 누적 쏠림 | 양봉 델타 일수 | 큰 양봉 횟수 |
|---|---|---|---|
| 5일 | 5일 델타 합계 ÷ 5일 거래량 **+20% 이상** | **4일 이상** / 5일 | **1회 이상** |
| 10일 | 10일 델타 합계 ÷ 10일 거래량 **+15% 이상** | **6일 이상** / 10일 | **2회 이상** |

- "큰 양봉" = 그날 델타가 평소 평균 델타 크기의 2배 이상인 날
- 누적 판정의 "평소"는 **누적 구간 바로 전 20일**입니다. 최근 큰 막대들이 평균을 부풀려서 오히려 빠지는 문제를 막기 위해서입니다.
- 마지막 날 막대가 작아도 최근 며칠간 매수가 이어졌다면 5일·10일 표에 잡힙니다.

### 공통 필터

주가 $5 이상, 20일 평균 거래대금 종목 $1,000만 / ETF $500만 이상

## 디스코드 알림 모양

종목과 ETF 각각 하루 · 5일 · 10일 표가 옵니다 (해당 없는 표는 생략). 같은 종목이 여러 표에 나오면 그만큼 매수가 꾸준하다는 뜻입니다.

```
🟩 거래량 델타 · 매수 우위 | 2026-10-29 마감
종목·ETF 수: 하루 1·1 / 5일 1·1 / 10일 1·1 (확인 793개)

📈 종목 · 하루 큰 양봉 (쏠림 30%↑ + 평균의 2배↑)
TICKER    델타$  쏠림% 평균x  RVOL  등락%  3일 50일  이름
NVDA      +151M    +81  15.9   2.4   +0.1  -++   위  NVIDIA

📈 종목 · 5일 누적 매수 우위 (쏠림 20%↑ · 양봉 4일↑ · 큰 양봉 1회↑)
TICKER 누적델타$  쏠림%  양봉 큰양봉  RVOL   5일% 50일  이름
LEN        +362M    +52   5/5      2   1.4   +0.4   위  Lennar

📈 종목 · 10일 누적 매수 우위 (…)
LEN        +463M    +39  9/10      3   1.3   +0.8   위  Lennar
```

| 열 | 의미 |
|---|---|
| 델타$ / 누적델타$ | 델타 × 종가 (달러 금액). 누적 표는 기간 합계 |
| 쏠림% | 델타 ÷ 거래량 (누적 표는 기간 합계끼리). 100%면 모든 5분봉이 상승 |
| 평균x | 하루 표: 델타 ÷ 최근 20일 평균 델타 크기. 하루 표는 이 값이 큰 순 |
| 양봉 | 기간 중 델타가 플러스인 날 수 |
| 큰양봉 | 기간 중 평소의 2배 넘는 양봉 델타가 나온 횟수 |
| RVOL | 하루 표: 그날 거래량 ÷ 평소 / 누적 표: 기간 평균 거래량 ÷ 평소 |
| 3일 | 최근 3일 델타 부호. `+++`면 3일 연속 매수 우위 |
| 등락% / 5일% / 10일% | 기간 주가 등락 |
| 50일 | 종가가 50일선 위/아래 |

누적 표는 "누적 델타 ÷ 평소 크기"가 큰 순이고, 표마다 최대 30줄까지 보여 줍니다.

## 해석 팁

| 모양 | 해석 |
|---|---|
| 쏠림% 높음 + RVOL 높음 + 50일선 위 | 상승 추세 중 강한 매수 유입, 가장 좋은 신호 |
| `+++` (3일 연속) | 하루짜리가 아니라 며칠째 매수 우위 |
| 쏠림% 높은데 RVOL 1 근처 | 거래량은 평소인데 방향만 한쪽, 조용한 매집 가능성 |
| 50일선 아래에서 큰 양봉 델타 | 하락 추세 중 반등 시도, 아직 확인 필요 |

장 마감 동시호가나 블록딜이 한 5분봉에 몰리면 델타가 왜곡될 수 있습니다. 진단으로 숫자를 함께 확인하세요.

## 설치 (새 저장소, 약 10분)

1. **디스코드**: 새 채널 생성 (예: `거래량-델타`) → ⚙ → 연동 → 웹후크 → 새 웹후크 → 채널이 새 채널인지 확인 → **웹후크 URL 복사**
2. **GitHub**: New repository (Public, 이름 예: `volume-delta`) → `delta.py`, `watchlist.txt`, `etfs.txt`, `requirements.txt`, `README.md` 업로드 → Commit
3. **Add file → Create new file** → 이름 칸에 `.github/workflows/main.yml` → zip 안의 같은 파일 내용을 붙여넣기 → Commit
4. **Settings → Secrets and variables → Actions → New repository secret**: Name `DISCORD_WEBHOOK_URL`, Secret에 1번 웹후크 주소
5. **Actions → Volume Delta Scanner → Run workflow**로 테스트 (15~20분)

## 목록 바꾸기

- `watchlist.txt`: `티커, 회사명` 형식 (MA 스캐너와 같은 파일, 그쪽에서 바꾸면 여기도 같이 바꿔 주세요)
- `etfs.txt`: `티커, 설명` 형식 (신호등·ETF 거래량과 같은 105개)
- S&P 500은 위키백과에서 1주일마다 자동 갱신

## 설정 바꾸기 (`delta.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `MIN_RATIO` | 30 | 매수 쏠림 기준(%). 알림이 많으면 40으로 |
| `MIN_MULT` | 2 | 평균 델타 크기 대비 배수 (하루 판정 + 누적의 "큰 양봉" 기준). 알림이 많으면 3으로 |
| `WINDOWS` | 5일 (20, 4, 1) / 10일 (15, 6, 2) | 누적 기간별 (쏠림% 최소, 양봉 최소 일수, 큰 양봉 최소 횟수). 기간을 추가하려면 `20: (10, 12, 3)`처럼 한 줄 더 |
| `BASE_DAYS` | 20 | 평균 비교 기간(거래일) |
| `MIN_PRICE` | 5 | 최소 주가($) |
| `MIN_DOLLAR_VOL` / `MIN_DOLLAR_VOL_ETF` | 1,000만 / 500만 | 최소 거래대금($) |
| `MAX_ROWS` | 30 | 표마다 최대 줄 수 |
